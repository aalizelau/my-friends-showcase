### 2026-08
date: 2026.08 · label: 職業、職涯選項與 career 討論

職業
- 在 CT good jobs（HKET 旗下）任 data scientist / ML engineer，月薪 32k。
- 做 data pipeline、similar job post search；趁 GPU 得閒 revamp 了 job post 的 tag prediction。
- 本來職缺是 developer，入職後被叫去做 ML；公司只有他一個在做 AI，但 developer／data engineer 有很多。
- 對 AI 的現實觀察：很多人對 AI 太過大想頭，沒資源的常以為能做很多；要用 AI 是因為連人都想不到 algorithm 怎麼寫，唯有用 data 找 pattern。framework 就那些 model，但 data distribution 不同都會令每個 situation 不一樣。

未來選項
- Cloud / security：若留現職再多考幾張 security cert，5 年後拿到相近薪水不難；通常要身兼多職（networking、infra），但 security 是企業不會砍的。
- CHAI Research（矽谷）：拿工作簽證去待幾年，同事都來自劍橋。220k USD／年（約港幣 137,500／月），稅 35–40%；不少朋友說這只是「矽谷貧民」程度。面試不難（k8s、LLM 基礎、python）。對方在 LinkedIn approach 他，long story。

我和他之間（討論 career planning）
- 他覺得我們鄉中給的視野真的很窄——miss cheung 老叫大家跟興趣揀科，但其實沒接觸過真的很難知道。
- 我們畢業時完全沒人揀 CS：初中學 Excel sum、學完 ICT 沒興趣；上大學才發覺 programming 幾得意。現在鄉中初中兩年前開始教 Python 了。
- 世界轉得很快；幸好他讀 phy 有些 transferable skills。同學一開始都揀醫療／金融科，因為老師來來去去就是「入了大學先、之後慢慢探索」。

# Refine Source — 通用 Prompt

把一段原始筆記（第一人稱、口語、零散、對話節錄都可以）整理成一則乾淨的「原始記錄（source）」，再貼進 app 的「＋新增記錄」。
同一個 prompt 也可用來重新精修一則**既有** source——把現有原文貼進去即可。

用法：把下面整段複製給 AI，然後在最後貼上你的原始筆記。

---

```
你是我的關係手帳的筆記整理助手。我會在最後給你一段關於某位朋友的原始筆記。
請把它整理成一則乾淨的「原始記錄（source）」，嚴格遵守以下規則：

【人稱】
- 朋友一律第三人稱：他／她。
- 記錄者（我）維持「我」。
- 例外：「友誼高光 / 我們之間」這類講「我和他之間」的內容，維持「我＝記錄者、他＝朋友」。
- 原文裡的對話（例如「你問我…」）改寫成敘述（例如「他問我…」）。

【忠實，絕不腦補】
- 只轉述，不新增、不推論、不臆測任何事實。
- 保留不確定的語氣（例如「太 T 還是太 J 他自己也記不清」「老家可能在杭州？」）。
- 我若標了「原話」的段落，一字不改照抄。

【精簡但保味道】
- 口語 → 精簡書面，但保留原味詞與專有名詞（例如 WLB、Prophet、house warming、jazz、high、call、fd、Suno AI）。
- 沒講完的線索留一句鉤子（例如「他說之後再詳細講」）。

【結構】
- 原文若有小標題，原樣保留：不要改名、不要新增、不要合併。
- 每個小標題下用簡短條列（- 開頭）。
- 只輸出整理後的內容本身，不要前言、不要總結、不要解釋。

【這則記錄的定位】
- source 是「唯一真相」層，之後的 now / topics / 友誼高光 / todo 都會從這裡重新整理（重生）出來。
- 所以事實要完整、可追溯；凡是我之後想放進摘要的重點，這裡都要有對應的原文。

（可選）整理完，另起一行用「標題建議：」給一個 12 字內的短標題。

原始筆記：
<在這裡貼上原始筆記>
```

---

## 備註
- 這份 prompt 只負責整理 **text**（原文）。日期、標題在「＋新增記錄」的欄位另填；上面的「標題建議」只是方便你參考。
- 想做別種精修（例如只除贅字、翻譯、統一時態），把【】其中一節換成你要的規則即可，其他保持不變。
- 契約背景見 [profile-schema.md](profile-schema.md)：sources 永久、可重生層（now/topics/relationship/todo）必須錨定於 sources。
